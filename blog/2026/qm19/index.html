Okay, new scenario. Alice is sending Bob a qubit, and it’s either or , and she flips a coin to decide which. So is this a description of the state of the qubit?

Nope. That’s a qubit state that Alice is definitely not going to send. All the way back at the start we swore never to be wishy washy and always remember that a state is a sharply defined arrow, and if you think of it as a superposition that’s a matter of interpretation. What we have here is sometimes called classical uncertainty. Put more simply, we know Alice is going to send one of two states, we don’t know which one, but we know they’re equally likely.

We can represent this state of knowledge (which is not the same thing as a state as we’ve been using that term so far) by weighting each state projection operator by its probability and adding the results:

So a matrix can describe our state of knowledge when it has some uncertainty about it, and in this case it’s a different thing from the so-called quantum uncertainty we hear about. There is a fact in the world, and Alice knows that fact, but Bob doesn’t. Alice and Bob would each make a different matrix to describe their own state of knowledge.

Alice would describe her state of knowledge with a pure state, a projection operator that is equivalent to a definite state vector. Bob would describe his state of knowledge with a mixed state (in this context a somewhat misleading term), which is the sum of all the possible pure state matrices, each weighted by its probability. The collective term for these is a density operator, after the classical concept of a probability density function, although it’s more common to hear the matrix representation of such an operator referred to as a density matrix.

But there’s a much more interesting application of these ideas, one which ties together much of the themes we’ve been wrestling with, even the dreaded measurement problem.
