The only other form the mystery function is allowed to take is to be balanced, and I said that was going to seem contrived. What it means for the state is that exactly half the terms contributing to it will be positive and half will be negative, and this will be entirely the function’s doing (Hadamard leaves all-zeros states alone.) The first (inner) Hadamard makes a term for every possible value, all of them positive, the mystery function flips the sign of half of them, and the final (outer) Hadamard creates from each a contribution that preserves the sign of the term it came from. This means that all the contributions cancel out, leaving a zero probability of measuring the all-zeros pattern.

The end result is that a measurement of will only happen if it was absolutely certain to happen, because the mystery function is constant. If it is balanced, is impossible, so something else will be found (at least one qubit will be in the state.)

Because of the peculiar contrivance of the setup, this is not at all useful. But it demonstrates how a quantum algorithm can produce a deterministic result, and seemingly explore a potentially huge problem space in a simple and practically instantaneous process. With qubits, the number of basis vectors is , about the number of atoms in the visible universe, and yet we seem to be able to probe the behaviour of a function on all of them, all at once.
